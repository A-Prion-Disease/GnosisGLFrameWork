- I gave thematic names, will change most eventually ; this repository thus far is heavily driven by 3rd party libraries 

- To compile make a directory inside Gnosis and run ' cmake.. ' and then 'make' inside the directory from your terminal

- as of the creation of this project it is heavily influenced by Cherno and LearnOpenGL to the point I feel I should acknowledge it; however I did not blatantly rip them off but rather did things my own way and drew influence from those resources.

**Features thus far:**
- Dynamic Rendering using OpenGL,
- Usable Framework (Though not great & not yet in made into library instead its currently a testing ground with the library)
- TextureAtlas Capabilities (For Spritesheets),
- Ability to stretch Width & Height

  **Dependencies:**

- glad (included in provisions),
- stb_image (included in provisions),

- SDL3 (Fetched by CMake)
- glm (Fetched by CMake)
